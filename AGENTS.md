# Stack

- **Framework:** Next.js 16 (App Router, Turbopack dev), React 19
- **Backend:** Convex 1.38 (schema, queries, mutations, actions, auth, HTTP router, migrations)
- **Auth:** `@convex-dev/auth` with Password provider
- **Styling:** Tailwind CSS v4 (CSS-first config in `globals.css` via `@theme inline {}` — no `tailwind.config.js`)
- **UI:** shadcn/ui (Radix-Luma style), lucide-react, `@base-ui/react`, `radix-ui`
- **Forms/validation:** zod 4
- **Linting/formatting:** Biome 2.4 (replaces ESLint + Prettier entirely)
- **Package manager:** pnpm
- **Testing:** Vitest + `convex-test` (in-memory Convex backend)

# Testing

- Tests live in `convex/` next to implementation files (e.g., `convex/users/staff-management.test.ts`)
- Uses `convex-test` — create a harness via `convexTest({ schema, modules })`, then `t.query()` / `t.mutation()`
- Auth functions (`getAuthUserId`, `createAccount` from `@convex-dev/auth/server`) are mocked with `vi.mock` + `vi.hoisted`
- Some Convex internals require `ctx as unknown as never` casts in tests

# Convex

- `convex/_generated/` is auto-generated by `convex dev` — do not edit
- Schema in `convex/schema.ts` — 8 tables: `users`, `products`, `suppliers`, `batches`, `dispatches`, `dispatchItems`, `stockAdjustments`, `auditLogs`
- Roles: `owner` (full access) → redirects to `/dashboard`, `staff` (products only) → redirects to `/products`
- `convex/init.ts` seeds the owner account (internal action)
- `convex/migrations.ts` — two data migrations (backfill roles/statuses) using `@convex-dev/migrations`

# Code conventions

- **No semicolons**, double quotes, trailing commas (ES5), arrow parens always
- **ESM only** — no CommonJS (`noCommonJs: error`)
- **No `any`** — `noExplicitAny: error`
- `@/` path alias maps to project root
- Feature directories under `features/<name>/hooks/` and `features/<name>/components/`
- `components/ui/` is shadcn-managed and excluded from Biome — do not edit manually
- `z.email()` (zod v4), `SubmitEvent` from React (React 19)

# Architecture

- **Convex is the sole backend** — no REST API or server-side framework beyond it
- Route protection: `proxy.ts` middleware using `@convex-dev/auth/nextjs/server`
- DB domain logic is in `convex/<table>/` (e.g., `convex/users/create.ts`)
- App pages in `app/(dashboard)/` and `app/(auth)/` route groups
